VAGNLSYS = Vagn Label System

Programmet är gjort för att underlätta att skapa order beskrivning som man kan skriva ut och klistra/tejpa fast på inkommande vagnar, för att märka upp vart vagnen kommer ifrån och vad som är fel. Programmet behövs ej installeras på användarens dator.

VAGNLSYS är under utvecklig och buggar kan förekomma. 

Utveckligen görst på en ARCH baserad os, windows exe filer compileras på en windows server vm med hjälp av PyInstaller.
